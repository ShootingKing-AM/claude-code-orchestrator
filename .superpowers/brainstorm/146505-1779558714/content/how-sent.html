How should attached files reach Claude?

The orchestrator runs Claude as a CLI subprocess. Files need to get into Claude's context somehow.

A

Save to disk, pass the path

Server saves the uploaded file to a temp directory, then injects its path into the prompt text — e.g. "See attached file at /tmp/abc/screenshot.png". Simple and works for any file type.

B

Inline base64 in prompt

File content is base64-encoded and embedded directly in the message text. Works without disk I/O but balloons prompt size for large files.

C

Claude's native file/image API

Pass images as vision content blocks and files via the Files API. Most capable but requires switching from CLI to direct API calls for jobs with attachments.
