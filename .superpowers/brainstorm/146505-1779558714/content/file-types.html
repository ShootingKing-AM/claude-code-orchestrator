What should be attachable?

Which types of files do you want to be able to paste or drag in?

A

Images

Screenshots, diagrams, mockups — PNG, JPG, GIF, WebP. Claude can read and reason about image content.

B

Text / code files

.txt, .md, .py, .js, etc. — pasted as readable text into the message.

C

Any file (base64)

PDFs, ZIPs, binaries — encoded and passed to Claude. Useful but bulky for large files.
