How should attachments appear in the UI?

After you paste or drop a file, what should you see before sending?

A

Filename chips above the input

Small removable tags (e.g. "📎 screenshot.png ✕") appear above the text box. Clean, compact, familiar from email clients.

B

Thumbnail preview for images, chip for others

Images show a small inline thumbnail; non-image files show a filename chip. More visual feedback for screenshots.

C

Inject path into text automatically

No separate attachment UI — the file path is just appended to the text input directly. Minimal, but less easy to remove.
